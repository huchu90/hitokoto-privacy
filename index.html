개인정보처리방침

今日のひとこと (오늘의 한마디)

今日のひとこと(이하 “앱”)은 회원가입이나 로그인이 없고, 이름·이메일·전화번호처럼 이용자를 직접 알아볼 수 있는 정보를 받지 않습니다. 다만 무료로 운영하기 위해 광고를 보여 주고, 앱을 개선하기 위해 사용 통계와 오류 기록을 모읍니다. 이 방침은 그 과정에서 어떤 정보가 어디로 전달되는지 설명합니다.

1. 기기 안에만 저장되는 정보

  • 저장한 문장 목록과 저장한 시각
  • 앱 설정(후리가나 표시 등)과 내려받은 콘텐츠

이 정보는 이용자의 기기 안에만 저장되며 개발자에게 전송되지 않습니다. 앱을 삭제하면 함께 지워집니다.

2. 외부 서비스로 전달되는 정보

앱에는 아래 외부 서비스가 포함되어 있으며, 각 서비스는 자체 방침에 따라 정보를 처리합니다.

서비스 (제공 회사)전달되는 정보목적
Google AdMob (Google LLC) 광고 ID, IP 주소, 기기 모델·OS 버전, 광고 노출·클릭 기록 광고 표시, 광고 성과 측정, 부정 클릭 방지
Firebase Analytics (Google LLC) 앱 인스턴스 ID, 사용 이벤트(어떤 문장을 보거나 저장·공유·재생했는지 등 문장 ID와 화면 상태), 기기 모델·OS 버전·앱 버전, IP 주소로 추정한 국가 등 대략적 위치 어떤 기능과 문장이 쓰이는지 파악해 앱 개선
Firebase Crashlytics (Google LLC) 앱이 멈추거나 오류가 났을 때의 오류 기록, 기기 상태(모델, OS 버전, 메모리 등), 설치 식별자 오류 원인 파악과 수정
GitHub (GitHub, Inc.) 새 문장을 내려받을 때 일반적인 인터넷 접속 정보(IP 주소 등) 새 콘텐츠 다운로드

사용 통계에는 이용자가 입력한 글이나 연락처 같은 개인정보를 담지 않습니다. 앱에는 글을 입력하는 기능이 없습니다.

각 서비스의 개인정보처리방침

  • Google 개인정보처리방침
  • Google 파트너 사이트·앱에서의 데이터 사용
  • Firebase 개인정보 보호
  • GitHub 개인정보처리방침

3. 앱이 직접 하지 않는 일

  • 개발자가 운영하는 서버는 없으며, 개발자가 이용자 정보를 따로 모으거나 판매하지 않습니다.
  • 위치, 카메라, 마이크, 연락처, 사진 등에 접근하는 권한을 요청하지 않습니다. 앱이 쓰는 권한은 인터넷 접속뿐입니다.
  • 발음 듣기는 기기에 설치된 음성 합성(TTS) 엔진을 사용합니다. 앱은 읽을 문장만 엔진에 넘기며, 개발자에게 전송하지 않습니다.
  • 공유하기는 이용자가 직접 고른 앱으로만 문장과 이미지를 보냅니다.

4. 보관 기간

  • 기기 안의 정보: 앱을 삭제할 때까지
  • Firebase Analytics 사용 이벤트: 수집 후 2개월이 지나면 삭제되도록 설정되어 있습니다.
  • Crashlytics 오류 기록: 수집 후 90일이 지나면 삭제됩니다.
  • AdMob이 처리하는 정보: Google의 방침에 따라 보관됩니다.

5. 광고 맞춤 설정과 선택권

  • Android: 기기 설정 → Google → 광고에서 광고 ID를 재설정하거나 삭제하면 맞춤 광고를 받지 않을 수 있습니다.
  • iPhone: 앱이 처음 광고를 보여 주기 전에 추적 허용 여부를 묻습니다. 허용하지 않으면 광고 ID가 전달되지 않으며, 설정 → 개인정보 보호 및 보안 → 추적에서 언제든 바꿀 수 있습니다.
  • 유럽경제지역(EEA)·영국 등 법으로 동의가 필요한 지역에서는 광고를 보여 주기 전에 Google의 동의 화면을 띄우며, 동의하지 않아도 앱의 모든 학습 기능을 쓸 수 있습니다.
  • 앱을 삭제하면 기기 안의 정보와 앱 인스턴스 ID가 함께 지워집니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.
